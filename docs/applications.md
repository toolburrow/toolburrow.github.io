### 打算怎麼推廣商品

全站的做法一致，申請表問「推廣方式」時可以用這段：

- 中文：在相關工具頁的計算結果下方，放 1～3 個和該工具直接相關的推薦商品，並附一句推薦原因，例如電阻色碼頁推薦電阻包和三用電錶。連結清楚標示為聯盟連結。不使用彈出視窗、不寄送電子報、不在社群洗版，流量來源是 Google 自然搜尋。
- English: Each tool page shows 1 to 3 products directly related to that tool below the results, each with a one-sentence reason (for example, resistor kits and multimeters on the resistor color code page). Links are clearly labeled as affiliate links. No pop-ups, email lists or paid traffic; visitors come from organic search.

### Google AdSense（全站）

用在：全站。

**申請條件**（2026-10-20 查詢）

- 官方條件：內容要「高品質、原創，並能吸引讀者」；要能存取網站的 HTML 原始碼；年滿 18 歲；網站要符合計畫政策（[AdSense 資格條件](https://support.google.com/adsense/answer/9724)）。
- 第三方說明指出，免費主機的子網域通常不被接受，要用自己的網域申請。`toollamp.github.io` 屬於這種情況，所以照計畫等買了自有網域再申請。官方頁面沒有直接寫到 github.io，標為待確認。
- 申請前要做的事：買網域並設定到 GitHub Pages、更新 canonical 和 sitemap 的網址、完成第 6 階段的廣告版位、更新兩份隱私權政策（AdSense 會使用 cookie）。
