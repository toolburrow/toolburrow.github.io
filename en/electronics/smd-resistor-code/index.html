How to read SMD resistor codes

SMD resistors of size 0603 and larger usually carry a short code. There are three systems, and you can tell them apart by the number of digits and whether there is a letter at the end. Resistors of size 0402 and smaller usually have no marking, so you have to measure them.

  • 3-digit code, usually ±5%: the first two digits are the value and the third is the number of zeros. 103 is 10 followed by three zeros, which is 10 kΩ. 472 is 4.7 kΩ.
  • 4-digit code, usually ±1%: the first three digits are the value and the fourth is the number of zeros. 1002 is 100 followed by two zeros, which is 10 kΩ. 4701 is 4.7 kΩ.
  • EIA-96 code, ±1%: two digits and a letter, used on small 1% parts. The digits are a position in the E96 series (table below) and the letter is the multiplier. 01C is 100 × 100 = 10 kΩ.

In 3-digit and 4-digit codes the letter R marks the decimal point: 4R7 is 4.7 Ω, R47 is 0.47 Ω and R010 is 0.01 Ω, a typical current sense resistor. A code of 0, 000 or 0000 is a zero-ohm resistor used as a jumper.

Frequently asked questions

What is a 103 SMD resistor?

103 is 10 × 10³ = 10 kΩ, usually with ±5% tolerance. The same value is marked 1002 on a 1% resistor and 01C in EIA-96.

Is 4R7 4.7 Ω or 4.7 kΩ?

4.7 Ω. On SMD resistors R always stands for the decimal point in ohms. Codes don’t use K or M; 4.7 kΩ is written 472 or 4701.

How do I tell a 3-digit code from an EIA-96 code?

An EIA-96 code always ends in a letter (01C, 68X). A 3-digit code is all digits, or has an R in the middle (4R7). If a code like 10R ends in R, it’s EIA-96 by the standard (1.24 Ω), but some makers use it for 10 Ω, so compare it with the other resistors on the board.
