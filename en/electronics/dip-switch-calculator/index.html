How DIP switches set a number

Each switch in a DIP switch is one bit of a binary number: ON is 1, OFF is 0. Switch 1 is worth 1, switch 2 is worth 2, switch 3 is worth 4, and each one after that doubles. Add up the switches that are ON to get the value.

For example, switches 1, 3 and 6 ON give 1 + 4 + 32 = 37. To set 37, take away the largest values that fit: 37 = 32 + 4 + 1, so turn on switches 6, 3 and 1.

DMX fixtures almost always use switch 1 = 1. Some boards and modules make switch 1 the highest bit instead; set “Switch 1 is” to “highest bit” for those, and check the manual or the board markings.

Setting a DMX address

One DMX512 line (a universe) carries 512 channels. A fixture’s address is the first channel it uses, and how many it uses depends on its mode. An 8-channel fixture at address 1 uses channels 1–8, so the next one starts at 9.

FAQ

What is switch 10 for?

Nine switches reach 511, so only address 512 needs switch 10. Many fixtures use switch 10 for something else, such as a standalone or channel mode. Check the fixture’s manual.

Is all OFF address 0?

It adds up to 0, but DMX addresses start at 1, so 0 is not a valid address. Some fixtures treat all OFF as a special mode and some as address 1, depending on the maker.

What if two fixtures share an address?

They receive the same data and do the same thing, which is handy when you want them in sync. Otherwise, make sure one fixture’s channels don’t overlap the next one’s; the planner above lays them out back to back.
