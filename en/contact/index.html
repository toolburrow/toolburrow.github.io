How to get in touch

Toolburrow takes feedback through GitHub Issues. Open a new issue on GitHub; you’ll need a free GitHub account. You can also check the issues already reported.

Reporting a wrong result

These details help find the problem quickly:

  • Which tool (the page URL is best)
  • What you entered
  • The result shown, and the result you expected
  • Your browser and device, for example Chrome on Android

Please note

GitHub issues are public. Don’t include personal details such as your phone number or address.

The site is run by one person, so replies may take a while, but every issue gets read.
