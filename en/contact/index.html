Contact

Report a problem or suggest a new tool through the feedback form.

Feedback form

The easiest way is the ToolLamp feedback form; no sign-in needed. It runs on Google Forms, and only the site’s maintainer sees what you send. Leave an email address if you’d like a reply, or leave it blank.

Every page also has a “Feedback” link at the bottom, and tool pages have a “Send feedback” link below the tool. These fill in which page you were on.

GitHub Issues

If you have a GitHub account, you can also open a new issue on GitHub or check the issues already reported. GitHub issues are public.

Reporting a wrong result

These details help find the problem quickly:

  • Which tool (the page URL is best)
  • What you entered
  • The result shown, and the result you expected
  • Your browser and device, for example Chrome on Android

Please note

Don’t include personal details such as your phone number or address.

The site is run by one person, so replies may take a while, but every message gets read.
