隱私權政策

最後更新：2026 年 10 月 20 日

你輸入的資料

所有工具的計算都在你的瀏覽器裡完成。你輸入的日期、數字等內容不會傳送到任何伺服器，ToolLamp 也不會儲存。

本站目前沒有做的事

  • 沒有使用 Google Analytics 或任何流量分析、追蹤程式。
  • 不需要註冊帳號，也不會要求你提供姓名、email 等個人資料。
  • 目前沒有放任何廣告。

存在你瀏覽器裡的資料

網站會用瀏覽器的 localStorage 記住你的三個選擇：

  • 按了右上角的深淺色切換按鈕：記住「light」或「dark」。
  • 切換了中文或英文：記住「zh-tw」或「en」，下次打開首頁就直接顯示這個語言。
  • 在工具頁按了「加入收藏」：記住你收藏了哪些工具（例如「life/bmi-calculator」），顯示在首頁的「我的收藏」。

還沒選過語言時，網站會讀取瀏覽器的語言設定和時區來決定先顯示中文還是英文。這個判斷在你的瀏覽器裡完成，不會傳出去。

這些資料只存在你的裝置上，不會傳出去，清除瀏覽器的網站資料就會刪掉。本站沒有設定任何 cookie。

「複製收藏連結」會把收藏清單寫在網址裡（例如 /zh-tw/?fav=life/bmi-calculator），只有你自己把連結分享出去，別人才會看到。打開這種連結時，網址會像打開任何網頁一樣送到 GitHub Pages。網站會先問你要不要加入收藏，你同意之後才會存進瀏覽器。

第三方服務

為了讓網站能運作，你的瀏覽器會連線到以下服務。它們會收到你的 IP 位址等一般連線資訊，並依照各自的隱私權政策處理：

  • GitHub Pages：本站放在 GitHub Pages 上。GitHub 可能會為了維護網站安全而記錄訪客的 IP 位址。請見 GitHub 隱私權聲明。
  • Google Fonts：標題字型從 Google Fonts 載入。請見 Google 隱私權政策。

聯盟連結

部分頁面之後可能會放上商品推薦的聯盟連結，並且會清楚標示。點擊這類連結後，你會前往商家的網站，商家可能使用 cookie 記錄你是從 ToolLamp 過去的，以便計算分潤。這些發生在商家網站上，適用商家自己的隱私權政策。ToolLamp 只會看到商家提供的點擊和成交統計，不會取得你的姓名、聯絡方式等個人資料。

未來可能加入的廣告

本站之後可能加入 Google AdSense 廣告，加入之前會先更新這份政策。屆時 Google 和它的合作夥伴可能使用 cookie，根據你造訪本站和其他網站的紀錄來顯示廣告。你可以在 Google 的廣告政策說明了解細節，也可以在 Google 的廣告設定裡關閉個人化廣告。

政策變更與聯絡

這份政策如果有變更，會更新在這個頁面，並修改上方的日期。有任何問題，請見聯絡我們。
