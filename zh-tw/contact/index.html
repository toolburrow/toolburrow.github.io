聯絡我們

回報錯誤或建議新工具，請填寫意見回饋表單。

意見回饋表單

最簡單的方式是填寫 ToolLamp 意見回饋表單，不用登入。表單放在 Google 表單上，只有網站維護者看得到你填的內容。想收到回覆的話，可以留下 email，不留也可以。

每一頁最下方也有「意見回饋」連結，工具頁的工具下方另有「填寫意見回饋」。從這些連結打開，會自動帶入你在看哪一頁。

GitHub Issues

如果你有 GitHub 帳號，也可以到 GitHub 新增一則 Issue，或先看看已經有人回報的問題。GitHub Issues 的內容是公開的，任何人都看得到。

回報計算錯誤時

請盡量寫下這些資訊，會比較快找到問題：

  • 哪一個工具（貼上網址最清楚）
  • 你輸入了什麼
  • 工具顯示的結果，以及你認為正確的結果
  • 使用的瀏覽器和裝置，例如 iPhone 的 Safari

請注意

請不要寫電話、地址、身分證字號等個人資料。

這是個人維護的網站，無法保證回覆時間，但每一則都會看。
