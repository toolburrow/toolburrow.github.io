聯絡我們

回報錯誤或建議新工具，請到 GitHub Issues 留言。

怎麼聯絡

ToolLamp 使用 GitHub Issues 接收意見。請到 GitHub 新增一則 Issue，需要先登入 GitHub 帳號（可以免費註冊）。你也可以先看看已經有人回報的問題。

回報計算錯誤時

請盡量寫下這些資訊，會比較快找到問題：

  • 哪一個工具（貼上網址最清楚）
  • 你輸入了什麼
  • 工具顯示的結果，以及你認為正確的結果
  • 使用的瀏覽器和裝置，例如 iPhone 的 Safari

請注意

GitHub Issues 的內容是公開的，任何人都看得到。請不要在裡面寫電話、地址、身分證字號等個人資料。

這是個人維護的網站，無法保證回覆時間，但每一則都會看。

ToolLamp：小而好用的線上工具。所有計算都在你的瀏覽器裡完成，不會上傳任何資料。
